Access & trial

These switches apply immediately, without a redeploy. The free trial is off by default.

Set to 0 to remove the per-IP cap. A low value such as 1 or 3 blocks bulk account creation; shared networks may need a higher value.

Ending trials revokes every currently active trial license; paid licenses are not touched.

Injector download

Champ ships as two files: public/downloads/champ.bat and public/downloads/champ.exe. The bat only starts the exe; the exe is the injector and puts the client into the Minecraft the customer already has open. There is no jar and nothing goes into mods.

Windowschamp.bat + champ.exe
Linuxchamp-client.tar.gz
File nameschamp.bat + champ.exe

A new release means rebuilding the injector (./native/build.sh for Windows, ./linux/build.sh for Linux) and deploying the site. There is nothing to upload here: the files in the deployment are the download, and every customer receives the same champ.bat and champ.exe.

Champ Beta (injector)

The same pair as the normal client, pointed at the beta package: start Minecraft, run champ.bat (or champ.exe), and it injects the beta client. Only this panel links it; the shop never offers it.
