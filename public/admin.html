Injector download

Champ ships as one injector: public/downloads/champ-client.exe. The client, the agent and the logo live inside that single file, and it injects into the Minecraft the customer already has open — there is no jar and nothing goes into mods.

Windowschamp-client.exe
Linuxchamp-client.tar.gz
FilenameRandom per download

A new release means rebuilding the injector (./native/build.sh for Windows, ./linux/build.sh for Linux) and deploying the site. There is nothing to upload here: the file in the deployment is the download, and every customer receives it under a random name.

Champ Beta (injector)

The same injector as the normal client, pointed at the beta package: start Minecraft, run this file, and it injects the beta client. Only this panel links it; the shop never offers it.
