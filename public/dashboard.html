Install Champ Client

One download, a few minutes, and you are in the game. No mods folder and no jar to find.

Windows 10 / 11Download the .exe and run it while the game is open.
LinuxA .tar.gz with the launcher, the client and the logo.

Fabric 1.21.11The profile you already play, with Fabric API installed.

The steps

Follow them in order — the game has to be running first.

  1. Download the client

    The button picks Windows (.exe) or Linux (.tar.gz) for this device automatically; on a phone or when the browser is unsure you choose yourself. Nothing goes into your mods folder, and every download gets its own file name, so keep it somewhere you can find it.

    Download Champ Client
  2. Linux: unpack, then run

    Unpack the archive (tar -xzf <file>.tar.gz -C ~/champ), make the launcher executable (chmod +x ~/champ/champ) and start ~/champ/champ with Minecraft open.

  3. Start Minecraft first

    Launch the Minecraft 1.21.11 profile you normally play and stay in the main menu. The client attaches to the game that is already running.

  4. Run the file and sign in

    While Minecraft is open, run what you downloaded and sign in with your Champ account. The splash checks your license, this PC and your network, then starts. Windows may ask for permission — that is expected. It closes itself once you see Champ is running.

  5. Locked to another network?

    Free and unlimited: press Reset IP in the splash, or Reset IP to this network under This device on the overview. A new router, a VPN or a move is never a lockout.

  6. Locked to another PC?

    One PC per key. Reset the device on the overview: the first reset is free, then one per week, after that €5. Resetting is what moves your key to the new PC.

  7. Starting again later

    Keep the file: start Minecraft, run it, done. The session is remembered, so it starts without typing anything. A newer release is a new download — the old one keeps working until you replace it.

Something not working? The exact error text plus your key and HWID makes a fix much faster — see Help.

How keys work

Read once, then you never have to think about it again.

  • One key links to one account and one PC, and it is yours until it expires.
  • A key from a reseller is activated on the overview — copy it exactly as it was sent.
  • A monthly plan renews through Stripe; a lifetime key never needs renewing.
  • Moving PC or network is a reset, not a new purchase: the first device reset is free.
