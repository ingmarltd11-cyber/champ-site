Setup

Install Champ Client

Get it running in a few minutes.

  1. Download the injector

    One .exe — the client sits inside it. Nothing goes into your mods folder, there is no jar to install, and every download gets its own file name, so keep it somewhere you can find it.

    Download Champ Injector
  2. Start Minecraft first

    Launch the Minecraft 1.21.11 profile you normally play (Fabric Loader + Fabric API) and stay in the main menu. The injector attaches to the game that is already running.

  3. Run the injector

    While Minecraft is open, run the file you downloaded and sign in with your Champ account. The splash checks your license, this PC and your network, then injects. Windows may ask for permission — that is the injection. It closes itself once you see Champ is running.

  4. Locked to another network?

    Free and unlimited: press Reset IP in the splash, or Reset network in Device, HWID & network above. A new router, a VPN or a move is never a lockout.

  5. Locked to another PC?

    One PC per key. Reset the device above: the first reset is free, then one per week, after that €5. Resetting is what moves your key to the new PC.

  6. Starting again later

    Keep the file: start Minecraft, run it, done. The session is remembered, so it injects without typing anything. A newer release is a new download — the old one keeps working until you replace it.
