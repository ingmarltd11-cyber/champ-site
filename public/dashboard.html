Install Champ Client

Get it running in a few minutes.

  1. Download your client

    Use the license card on Overview. Downloads require an active license.

  2. Install Fabric Loader

    Use Fabric Loader for the Minecraft version listed with your current release.

  3. Install Fabric API

    Install the required Fabric API version documented for that release.

  4. Put both JAR files in your mods folder and launch the matching Fabric profile.
