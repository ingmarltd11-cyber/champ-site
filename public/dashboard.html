Setup

Install Champ Client

Get it running in a few minutes.

  1. Download the loader

    The loader fetches the client JAR itself and asks the license server whether this PC is linked. Drop it in your mods folder.

    Download Champ Loader
  2. Install Fabric Loader & Fabric API

    Use Fabric Loader for the Minecraft version listed with your current release, and the Fabric API version for that release.

  3. Launch the matching Fabric profile

    On the first launch the loader downloads ChampClient.jar into mods. Close Minecraft fully and start it once more so Fabric loads the new client. If the download fails, grab the client here and place it in mods yourself.

  4. This PC is already linked?

    Nothing to type: the license is checked online and the client opens straight away. A key that is already bound to another PC is refused here.

  5. No license on this PC yet?

    The game opens the license screen. Paste the key from your purchase e-mail and press Activate; it is sent to the server once and is not stored on this PC. Already used on an old PC? Reset the device in Device & HWID above first.
